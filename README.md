# My Class Timetable — Weekly Planner

A simple weekly class timetable planner for university students, built with HTML, CSS and JavaScript.

## What it does

- **Today at a glance** — shows today's classes, the class happening now, and the next class with a live countdown ("starts in 1h 25m").
- **Weekly grid** — Monday to Saturday view of the whole week, with today highlighted.
- **Add your classes** — subject, day, start/end time, room and teacher. Warns you if a new class overlaps an existing one.
- **Delete / clear** — remove one class or clear the whole timetable.
- **Saved in your browser** — classes are stored in localStorage, so your timetable is still there when you come back. Nothing is uploaded anywhere.
- **Sample timetable** — one click loads a labelled sample timetable (marked "Sample") so you can see how it works. Delete the samples and add your real classes.

## Demo data

The sample timetable (Web Development, Database Systems, Data Structures, Operating Systems, English, Software Engineering) is demo data only, clearly marked "Sample" in the app.

## How to use

Open `index.html` in any browser. No build step, no server needed.

## Built with

HTML, CSS, JavaScript.
